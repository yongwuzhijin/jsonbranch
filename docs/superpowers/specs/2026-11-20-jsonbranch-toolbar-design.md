# 枝序 JSONBranch 工具栏设计说明

日期：2026-11-20
状态：待用户审阅。本文只描述设计，不包含实现。
目标仓库：https://github.com/yongwuzhijin/jsonbranch （公开）
本文路径：`docs/superpowers/specs/2026-11-20-jsonbranch-toolbar-design.md`
基线是当前分支上已实现的共享工作台。Orca 保持不变。macOS 窗口外层的打开、另存为、关闭不在本文范围。

## 1. 已定决定

共享 JSON 顶栏现有 11 个操作改为纯图标。功能名仍按当前界面语言提供中文或英文，同时写入 `title` 和 `aria-label`。可用控件有清晰的键盘焦点。行号和保留转义都是纯图标开关，使用 `aria-pressed`，选中时有明显的非文字视觉。原有禁用条件和功能保持不变。

另加两个纯图标按钮调节编辑区字号。字号是 12 到 24 的整数，步长 1，默认 13。到达下限或上限时对应按钮禁用。悬浮提示含当前字号。字号只作用于 Monaco 和 textarea 降级，不改变树的字号。Chrome 与 macOS 用同一套字号规则，各自记在本机，不进入文档正文，也不参与脏标记。旧偏好没有该字段，或值不合法时，回退到 13。

## 2. 范围

顶栏 11 个操作是：格式化、全部展开、全部折叠、行号、复制、复制路径、复制键值对、复制值、删除、撤销、清空。保留转义是第 12 个顶栏控件，由带文字的复选框改为纯图标开关。字号减小和字号增大是新增的第 13、第 14 个顶栏控件。

这些控件仍在 `packages/json-view` 的同一顶栏，扩展和 macOS 继续共用。不改树行上的复制键值对、复制路径、复制值、删除，以及行内展开或折叠。不改搜索框、上一处、下一处。不改分栏。不改 macOS 的打开、另存为、关闭。不改解析、格式化、搜索、删除和撤销的规则。

行号开关继续只控制右侧树是否显示行号。Monaco 自己的行号保持现状，不因这个开关关闭。保留转义继续只改变解析选项，不改变其它行为。

## 3. 顶栏外观与可访问性

每个顶栏控件只显示图标，不显示功能名文字。`title` 与 `aria-label` 使用同一句当前语言的功能名。中文和英文沿用现有文案：格式化 / Format，全部展开 / Expand all，全部折叠 / Collapse all，行号 / Line numbers，复制 / Copy，复制路径 / Copy path，复制键值对 / Copy pair，复制值 / Copy value，删除 / Delete，撤销 / Undo，清空 / Clear，保留转义 / Keep escapes。

图标使用已有的 `lucide-react` `0.577.0`。全部展开、全部折叠、复制路径、复制键值对、复制值、清空、保留转义补上图标。字号用一减一加两个图标。图标标记为装饰，不进入可访问名称。

可用控件在 `:focus-visible` 时显示至少 2px 的焦点环，颜色与顶栏背景可区分，不被 `outline: none` 去掉。鼠标点击可以不留下持久焦点环。禁用控件保留 `disabled`，不能触发操作，也不显示为选中。

行号和保留转义的 `aria-pressed` 与当前状态一致。选中时同时改变背景和边框，沿用现有强调色，不能只靠颜色传达。未选中时恢复普通按钮外观。

禁用语义不变：

- 解析结果不是成功时，格式化和复制禁用。
- 没有当前行时，复制路径、复制键值对、复制值禁用。
- 没有当前行，或当前行是根时，删除禁用。
- 没有可撤销文本时，撤销禁用。
- 字号为 12 时减小禁用。字号为 24 时增大禁用。

当前行的定义不变：优先用手点选的行，否则用当前搜索命中。

## 4. 字号数据流

共享界面提供一个纯函数，Chrome 和 macOS 都调用它：

`normalizeEditorFontSize(value: unknown): number`

只有有限的整数，并且在 12 到 24 闭区间内，才原样返回。缺失、`null`、非数字、数字字符串、小数、`NaN`、小于 12 或大于 24，都返回 13。不把越界值夹到边界。

减小把当前值减 1，增大把当前值加 1，结果再经过这个函数。按钮的 `title` 和 `aria-label` 包含动作和当前值。中文是「减小字号，当前 N」和「增大字号，当前 N」。英文是 “Decrease font size, current N” 和 “Increase font size, current N”。N 是按下之前的当前值。

`TextSlot` 接收这个整数。Monaco 的 `fontSize` 使用它。textarea 降级的字号也使用它。Monaco 尚未出现时的「正在打开编辑器」不要求跟随字号。树行字号保持 13px。

字号变化不调用修改文档正文的操作，不改变 `baseline`，不使 `isDirty` 变为真。

## 5. 宿主记忆与错误

字号与文档记录分开存放。

Chrome 继续用 `chrome.storage.local` 的 `document` 保存 `input`、`keepEscapes`、`showLineNumbers`。字号使用另一个键 `editorFontSize`，值是数字。读取时把该键的值交给 `normalizeEditorFontSize`。没有这个键与读取失败相同，都使用 13，并且不改写 `document`。写入失败时，本次会话保留用户刚选的字号，文档正文照常保存，界面给出一句不阻断编辑的提示：中文「字号未能记在本机」，英文 “Font size was not saved on this device.” 下次成功的字号写入再清除这句提示。

macOS 不把字号写入正在编辑的 `.json`，也不因此把窗口标成未存储。每个系统用户一份偏好，放在应用 userData 目录的独立文件里，内容只有字号。文件不存在、无法读取或内容不合法时使用 13。写入失败时同样保留本次会话的字号，并显示上面的提示，已打开文件的内容和脏标记不变。

两个宿主都不把字号放进撤销栈。

## 6. 测试与验收

共享纯函数用表覆盖：13 保持 13；12 和 24 保持原值；11、25、13.5、`"13"`、`null`、缺失和 `NaN` 都得到 13。

工作台测试确认顶栏控件的可访问名称仍是现有功能名，可见按钮文字不再包含功能名。行号和保留转义反映 `aria-pressed`。原有禁用用例继续有效。减小到 12 后减小按钮禁用，增大到 24 后增大按钮禁用。改变字号后，传给文本槽的值变化，表示脏标记的比较结果不变。树行字号测试或样式断言保持 13px。

宿主测试使用假的存储：Chrome 缺键和非法值得到 13，且不调用文档那条记录的写入。macOS 偏好文件缺失或损坏得到 13，打开中的文档路径和基线不变。字号写入失败时，内存中的字号仍是用户选择的值。

验收：

1. 顶栏 11 个操作和保留转义都只有图标，悬浮能看到当前语言的功能名，屏幕阅读器使用同一名称。
2. 键盘焦点移动到可用顶栏控件时能看见焦点环。
3. 行号和保留转义的按下状态与选中外观一致，功能与改前相同。
4. 字号从 13 起以 1 为步长在 12 到 24 之间变化，上下限按钮禁用，提示含当前值。
5. Monaco 与 textarea 使用该字号，树行仍是 13px。
6. 重新打开扩展或 macOS 应用后字号仍在。旧数据没有字号或字号非法时显示 13。改字号不把文档变成未存储，也不改文件内容。
7. macOS 的打开、另存为、关闭仍在窗口外层，外观和关闭三按钮行为不变。

## 7. 明确不做

不引入新的提示组件或图标包。不把搜索条改成文字按钮。不把树行按钮的可访问名称改成不带路径。不把字号写入 JSON 文档或撤销记录。不夹取越界字号。不在本设计中实现代码。
